Under the hood

The ReAct Pattern

🧠 REASON Which tool next?
→
🔧 ACT Call tool
→
👁 OBSERVE Read result
↩

Loop until LLM emits no tool calls → produces final answer

Not a script

We give the LLM three tools and a system prompt. It decides which to call, in what order — we don't hard-code the sequence.

Conditional exit

When stock is out, the LLM sees in_stock: false and produces a final answer directly. No if-else in our graph code.

60 seconds. "ReAct — Reason, Act, Observe. LLM reasons → emits tool_call → LangGraph runs it → appends result → LLM reads it and reasons again. Loop continues until no tool_calls. That's the exit. Key: we described the tools. The LLM infers the sequence."

LangGraph State Machine

START
↓
Agent Node  ·  LLM + 3 bound tools
↓   tool_calls?
↙ yes
Tools Node  ·  check_stock · price_order · delivery_eta
↩ back to agent
→ no
END  ·  final answer

State — message list; add_messages reducer handles merging automatically

Routing — tools_condition checks last message for tool_calls

Streaming — astream_events emits tokens + tool events live over SSE

Engineering decisions

Three choices that matter

🔄

LangGraph over plain chains

Chains are linear — they can't loop. LangGraph is a real state machine: the agent can call tools multiple times, re-read results, and exit when it's ready. That loop is what makes agentic behaviour possible.

📡

SSE streaming over REST polling

The agent takes 30–90 seconds. Streaming every thought token, every tool call, every result makes the wait productive — users watch the agent reason in real-time, not stare at a spinner.

⏳

Exponential backoff for API reliability

NVIDIA's free-tier returns HTTP 529 "overloaded" under concurrent load. The backend retries silently — 5 s, 10 s, 20 s — up to 4 attempts. Most overload errors clear within one retry. The user never sees it.

75 seconds. One decision, one sharp sentence each. Don't rush — these are the technical talking points that show depth. On backoff: mention the async_http_client bug only if asked — one-line wrong parameter name that got forwarded to the OpenAI API. Found by reading the warning log.
